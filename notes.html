Main tags

Head

The head element contains meta information about the document.

Body

The body element contains the visible content of the document.

Header

The header element contains introductory or navigational elements for the document.

Main

The main element contains the main content of the document.

Footer

The footer element contains information about the document, such as copyright information or links to related documents.

Div

The div element is a generic container for content that can be styled with CSS.

Span

The span element is a generic inline container for content that can be styled with CSS.

Formatting

h1-h6

The h1-h6 elements are heading elements, used to organise the content of the page.

br

The br element is a line break element, used to create a new line within a paragraph.

List

The list element is used to create ordered(ol) or unordered(ul) lists; use the tag "li" to add list items.
